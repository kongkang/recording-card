# Design Spec · 录音卡 5 套多方向重构方案

## 1. 目标受众与使用场景
- **核心用户**：高频开会、客户拜访、户外沟通、习惯口述备忘的职场人、产品/研发负责人、独立创作者。
- **典型场景**：
  - 咖啡桌/会议室盲按物理按键录音并在关键决策处单击打点（如 `14:26` 拍板导出延后两周）；
  - 会后快速浏览结构化结论、转发 Markdown/PDF/长图纪要，或顺手把刚拍的白板/界面照片按时间对齐进对话；
  - 睡前或通勤路上单手听/看原始转写、随手确认系统推测的说话人身份（如将「说话人 1（推测）」绑定为「老陈」）；
  - 通过 OS1 语音同频或轻聊直接追问历史录音细节与待办事项。

## 2. 核心功能底线（5 套方案必须全量保留且可真实交互）
1. **硬件连接与实时采集**：扫描配对自有硬件矩阵（`录音卡 V2 · T4W25T`、`点一机 V1 · B7K9Q2`、`语音 AI 键盘 V2.1 · L3M8N1`、可选 `Apple Watch`）；连接后隐藏本机录音开关，单一开关控制录音（开启后实时等宽跳表 + 灵动岛/锁屏实况 + 本机保底待命标签）；电量档位与保守估算（`电量高 · 可录至 今天 22:42`）；同步状态与手动同步三态反馈；Wi-Fi（已配置 2 个网络）与固件版本（`2.1.0 · 有可用更新`）；实时转写中状态提示块（不可勾选）。
2. **记录归档与现场相册对齐**：按日分组（今天 / 昨天）：
   - `14:20` **午后项目方向讨论**（`18分40秒` · 已合并 6 分片 · 含 `14:26` 物理按键打点 · 说话人 1 / 2（推测）· 本机离线转写）
   - `13:05` **客户回访要点**（`9分12秒` · 含 2 张现场照片 · 说话人 1 / 2（推测）· 被引用总结 1）
   - `10:12` **晨间工作计划**（`3分05秒` · 含 4 张现场照片 · 说话人 1（推测））
   - 昨日 `09:30` **与运维确认发布窗口**（`5分12秒` · 说话人 1（推测）/ 阿杰）
   - **今日未归类图片（1 张）**：支持一键归位到时间最接近的记录或移除。
3. **对话详情、原始数据与轻量声纹命名**：三 Tab（`对话详情` / `原始数据` / `被引用总结`）；清洗对话按时间插入现场照片（支持「不属于本段」移入未归类）与 `14:26` 打点标识；原始数据展示含口语停顿的原文与声波试听条；点击任意说话人弹出轻量「为说话人命名」弹层（名框 + `可能为：老陈` 提示 + `记住声纹` / `同改其余 4 处` 双勾选 + 最近使用 5 个名称，确认后跨界面实时刷新）。
4. **多选总结、结构化结果与导出**：支持勾选今日/本周/本月记录生成总结；总结结果页含 `全部 / 概览 / 逻辑结构 / 信息点 / 行动项 / 全文 / 来源记录`（全文合并连续同说话人发言；信息点支持展开并嵌入现场图与原话跳转；行动项可勾选并实时统计完成数；来源记录双向跳转详情）；右上角导出弹窗（完整文档 / Markdown / PDF / 长图 / Word）。
5. **OS1 语音/轻聊记忆空间**：双模切换——`沉浸通话`（声波同频态 + 上下文感知芯片如 `感知 14:26 排期拍板` + 话题引导）与 `轻聊`（检索本地录音、待办与联网资料，支持快捷提问与发送消息实时响应）。
6. **设置与隐私（本地离线优先）**：云端账号授权（`owner@wainao.chat`）、本地语音引擎（`SenseVoice INT8 + Silero VAD · 已就绪`）、云端润色模型、声纹识别（5 个常用自动识别槽位，第 1 槽位锁定「我的声音」+ 不限量手动人物库）、相册本地对齐开关、Apple Watch / 第三方硬件联动。

## 4. 交付与技术规范
- **输出位置**：`design-demos/index.html` 与 `design-demos/dir-1.html` ~ `design-demos/dir-5.html`
- **设备外壳**：严格对齐 `huashu-design/assets/ios_frame.jsx` iPhone 15 Pro（`393×852` 屏幕，124×36 Dynamic Island，54px Status Bar，Home Indicator）
- **交互交付形态**：每套方案在专属 `1440px` 构图展示板上平铺 **5 台独立可交互状态机**（分别初始落在：①主屏 / ②详情与声纹命名 / ③结构化总结与导出 / ④OS1 空间 / ⑤硬件与设置），且支持一键切换为「单机 1:1 沉浸体验」。
- **单文件离线可读**：零外部运行时 JS 框架依赖，全量图片 base64 内嵌，正文 `>= 14px`、标签 `>= 12px`、对比度 `>= 4.5:1`。
