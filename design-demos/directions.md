# 5 套设计方向卡 · Recording Card App 重构探索

> 遵循 `huashu-design` v3.5.0「先定形态，再画屏」与 `app-paradigms.md` 五问原则。5 套方向在**主屏形态、签名物件、数据形状、色彩语义、文字嗓音与展示板构图**上彻底拉开差距，核心功能 100% 保持一致。

---

## 方向一：`dir-1.html` · 声波仪 Field Deck
- **灵感与范式**：`01 界面即世界` + `02 签名物件` ｜ Teenage Engineering OP-1 / EP-133 + Braun Dieter Rams 精密声学仪器思维
- **借什么 / 不借什么**：借「实体液晶取景窗 + 物理按压厚度按键 + 丝印网格分区」的操作直觉；不借音乐合成器的音阶/BPM 概念，全部重组为录音卡硬件状态、分段声轨与物理打点交互。
- **app-paradigms 五问**：
  1. **主屏形态**：上半部是可实时操作的「录音卡 V2 实体示波面板」（OLED 点阵波形窗 + 物理拨杆与 4 枚丝印快捷键），下半部是磁带卡槽式分段索引。
  2. **签名处（120% 质感）**：黑底液晶示波屏 + 带 `inset` 物理键程的 `MRK 打点` 按键 + `14:26` 信号橙刻度标尺。
  3. **数据的形状**：录音记录是磁带式水平音轨卡，时长用分片刻度条与等宽字符表达，物理打点显示为实体橙色插销标记。
  4. **颜色回答什么**：国际信号橙 `#FF4D00` 只回答一件事——「当前激活态 / 正在录制 / 用户物理打点」。工业暖灰 `#E6E5E0` 与纸白 `#F4F3EE` 承担全盘结构。
  5. **嗓音**：`Space Mono`（等宽读数、分片码）+ `Noto Sans SC`（700/500）；冷静克制如德系声学工程师（「00:12:34 · 6 分片已合并 · 端侧声纹 94%」）。
- **展示板构图**：`closeup` 局部特写式（工程方格浅灰底板；左 1.0x 主屏 + 中央 2.1x 放大可点击特写示波操控台 + 右侧与底侧 4 台错落设备）。
- **form 来自内容的哪里**：录音卡本身就是一张贴身随行的精密硬件声学采集器，软件应该像硬件的实体延伸面板，而不是又一层抽象网页表单。

## 方向二：`dir-2.html` · 昼夜声轴 Chronos Ribbon
- **灵感与范式**：`03 时间有形状` + `06 AI 落在物上` ｜ Structured / Tiimo ★ + 瑞士国际主义时间网格
- **借什么 / 不借什么**：借「真实时间比例条带 + 沿轴线直出任务/节点」的空间时间感；不借日程待办的紫粉配色与插画贴纸，改用瑞士冷纸建筑格线与声学时间戳语义。
- **app-paradigms 五问**：
  1. **主屏形态**：按 `09:00 → 18:00` 真实分钟比例拉伸的垂直昼夜声轴，静音留白如实拉开间距，现场照片直接悬停在拍摄时刻刻度旁。
  2. **签名处（120% 质感）**：比例昼夜时间标尺 + 贯穿轴线的 `14:26` 关键决策刻度指针 + 直接沿时间轴框选合并的「时段总结抽屉」。
  3. **数据的形状**：会议不是等高卡片，`18分40秒` 的午后讨论高度明显长于 `3分05秒` 晨会；AI 提炼内容以钴蓝角标直接附着在时间块右缘。
  4. **颜色回答什么**：钴蓝 `#2563EB` 专指「AI 整理/总结/推理产物」，赤红 `#DC2626` 仅指实时采集态，其余严守暖冷纸白 `#F7F6F2` 与炭黑 `#141517`。
  5. **嗓音**：`Instrument Serif`（大号日期时间）+ `JetBrains Mono`（`tabular-nums` 刻度）+ `Noto Sans SC`；清醒精准如时间建筑师。
- **展示板构图**：`flow` 流程串联式（瑞士网格冷白底板；5 台手机按一天真实动线斜向阶梯排布，虚线 SVG 连线标注跳转路径与触发动作）。
- **form 来自内容的哪里**：人每天的记忆本来就按时间流逝并存在长短与留白，只有恢复时间的真实比例，才能一眼看出今天哪段谈话真正分量最重。

## 方向三：`dir-3.html` · 卷宗编辑部 Archival Folio
- **灵感与范式**：`05 内容当主角` + `08 可达性定形式` ｜ 吕敬人书籍装帧设计 + 东亚深度社论出版语法（5 套中唯一暖纸衬线方案）
- **借什么 / 不借什么**：借「天头地脚呼吸留白 + 切口旁注栏 + 朱砂一处点睛」的慢读版式动作；不借古籍竖排繁文，适配现代中文高可读性竖向长读体验。
- **app-paradigms 五问**：
  1. **主屏形态**：每日自动编排的「个人口述日报与卷宗头版」——打开先读今日最重的一条结论（「导出延后两周，周五前出小方案」），紧随「今日三事」索引与未归类照片夹页。
  2. **签名处（120% 质感）**：头版结论引文 + 对话详情「正文栏 + 右侧窄旁注栏」双栏排印 + `14:26` 朱砂印章式重点批注。
  3. **数据的形状**：对话被编辑成可精读的口述体纪要与边注，说话人推测以克制旁注落款，点击即可一锤定音归档。
  4. **颜色回答什么**：朱砂红 `#B83227` 只回答「个人亲手打点 / 实时收音红印 / 核心结论圈点」，底色取宣纸暖白 `#F5F0E6` 与徽墨 `#1A1916`。
  5. **嗓音**：`Noto Serif SC`（900/700 标题与核心引文）+ `Noto Sans SC`（辅助导航与功能按钮）；温润沉静如私人传记编辑。
- **展示板构图**：`hero` 主次书卷展板式（暖宣纸色带极淡装帧折痕底板；左侧 1.25x 主屏突出今日头版，右侧两列错落排布其余 4 台与色板题签）。
- **form 来自内容的哪里**：产品主张「不用翻几小时录音，打开就是结论」，最自然的形态就是一本每天替你编校成册的私人纪要报纸。

## 方向四：`dir-4.html` · 暗房声场 Nocturne Studio
- **灵感与范式**：`04 一套语义色` + `06 AI 落在物上` ｜ Halide / Bevel 暗光单手精密操控仪器（严格规避 GitHub-dark 蓝紫霓虹 slop）
- **借什么 / 不借什么**：借「纯黑暗场省电对比 + 发丝线刻度尺 + 单手拇指热区控制」；不借相机取景参数，改造成声学能量光谱尺与双人声纹轮替图。
- **app-paradigms 五问**：
  1. **主屏形态**：OLED 纯黑高对比声学暗房，取消厚重卡片框线，靠明度阶梯与 1px 发丝线分隔每条录音的声学能量条与结论摘要。
  2. **签名处（120% 质感）**：可点击交互的「全宽声学能量光谱尺（Acoustic Scrub Bar）」，标出人声密度、静音隙与 `14:26` 琥珀拍板尖峰；底部悬浮拇指指令舱。
  3. **数据的形状**：每段录音都有一条可视化声纹条形图与余弦置信度读数（`CAM++ 94%` / `76% 临界`），重要结论直接嵌在波形下方。
  4. **颜色回答什么**：仪表琥珀金 `#F5A623` 只指「焦点声纹 / 物理打点 / 活跃控制」，翡翠绿 `#22C55E` 仅指示 BLE 硬件在线，深黑 `#0A0B0D` 与碳墨 `#141619` 构建无干扰暗场。
  5. **嗓音**：`JetBrains Mono`（毫秒精度码、相似度数值）+ `Noto Sans SC`；低噪专注如夜航仪表。
- **展示板构图**：暗场全景展墙（深炭黑细腻纹理底板 + 顶部贯穿声学刻度坐标标尺；主屏偏左放大，右侧两层非对称展墙呈阶梯错落）。
- **form 来自内容的哪里**：大量录音发生在暗光会议室、车载夜路或隐蔽通勤途中，用户需要低眩光、单手拇指可达、声学与重点一眼扫清的专业界面。

## 方向五：`dir-5.html` · 灵动叠卡 Liquid Folio
- **灵感与范式**：`02 签名物件` + `07 活态载体` ｜ Apple iOS 26 Liquid Glass + Cosmos / Raylie 空气感空间叠卡美学
- **借什么 / 不借什么**：借「顶部状态光色视窗 + 悬浮半透明玻璃胶囊导航 + 轻量空间卡片景深」；诚实遵守 HTML 限制——不伪造复杂物理折射，明确用 `backdrop-filter: blur(22px) saturate(180%)` + 1px 顶部高光描边表达，且仅悬浮导航与浮层使用玻璃态。
- **app-paradigms 五问**：
  1. **主屏形态**：顶部是一块随硬件与对话状态流动变色的「今日声景视窗」（录音中暖珊瑚、复盘时深湖青雾、待机时鼠尾草绿），下方承载轻量圆角叠卡，底部悬浮液态玻璃药丸导航。
  2. **签名处（120% 质感）**：随产品状态切换光色的「活态声景视窗」+ 底部三槽位悬浮玻璃药丸栏（随时可拉出 OS1 暖珊瑚同频圆环）。
  3. **数据的形状**：未归类照片、分段记录、生成总结如同桌面可抽出翻阅的实体活页叠卡，写真图片大面积自然透气呈现。
  4. **颜色回答什么**：视窗光色只回答「当前处于采集（暖珊瑚 `#E85D3F`）、复盘整理（深湖青 `#1D6F72`）还是待命归档（鼠尾草 `#3B7A57`）」。
  5. **嗓音**：`Plus Jakarta Sans` + `Noto Sans SC`；温和体贴、克制不打扰的随身伙伴口气。
- **展示板构图**：空气感空间悬浮板（冷暖空气雾面底板；主屏居中放大，左右各错落悬浮 2 台副屏，右下角附一枚磨砂玻璃状态色说明牌）。
- **form 来自内容的哪里**：当录音变成一种无感伴随的日常习惯，界面不该像冷冰冰的工单或表格，而应像随手可翻、与生活空间融为一体的活态卡片桌。
