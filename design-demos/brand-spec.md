# Brand Spec · 录音卡（Recording Card）

> 依据 `huashu-design` v3.5.0 品牌资产协议与真实工作区资产固化。所有 5 套设计方案共享同一套真实品牌与产品事实，差异在于信息架构、交互范式与视觉诠释。

## 1. 品牌与产品定位
- **产品名称**：录音卡
- **核心主张**：别再边听边记，专心聊，它替你记住。不用翻几小时录音，打开就是结论。
- **产品形态**：超薄便携 AI 录音硬件矩阵 + 本地优先离线转写与声纹聚类 App + 记忆检索/语音同频空间（OS1）。

## 2. 官方视觉资产真源
- **App 图标真源**：`app/assets/icon/app_icon.svg`（1024×1024）
  - **视觉意象**：浅纸底板（`#FDFDFB` → `#EFEFE8`）上的深墨圆角硬件卡片（`#1D1D1F`）+ 五根对称胶囊录音电平波纹（`#FAFAF8`）+ 右上角红色录音指示点（`#FF3B30`）。
  - **核心隐喻**：实体硬件卡片 + 真实声波刻度 + 一眼可辨的红色收录指示灯。
- **自有硬件矩阵**：
  - `录音卡 V2 · T4W25T`（固件 2.1.0，支持机身实体打点与无线同步）
  - `点一机 V1 · B7K9Q2`
  - `语音 AI 键盘 V2.1 · L3M8N1`
  - 可选扩展：`Apple Watch 联动`（默认关闭，开启后接入第 4 款硬件扫描）

## 3. 产品核心真实性与隐私红线（5 套方案均不可违背）
1. **本地转写优先**：SenseVoice INT8 + Silero VAD 端侧离线转写；音频切片、转写文本与声纹 embedding 默认留在本机，云端仅在授权后用于窗口润色与话题分段总结。
2. **说话人诚实标识**：声纹由端侧 3D-Speaker CAM++ 聚类，未获用户确认前一律明确标注「说话人 1（推测）」「说话人 2（推测）」，可给出上下文候选提示（如 `可能为：老陈`），绝不断言真实身份。
3. **硬件优先与零功耗保底待命**：已连接硬件时仅显示单一录音开关（不并行开启手机麦克风耗电），同时启用零功耗本机保底待命 + 灵动岛/锁屏实况；电量只以「高 / 中 / 低 + 保守可录至时点」呈现，不编造虚高百分比。
4. **物理操作语义**：单击 = 重点打点（如 `14:26` 排期拍板）；长按 = 语音唤起 Agent；双击 = 预留自定义。
5. **真实上线质感**：界面按正式发布形态设计，绝不出现「模拟 / 演示 / Demo」字样或 Lorem 占位文本。
