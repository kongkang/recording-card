## 当前设计基线（2026-11-07 v3 打磨）

- 顶栏即导航：首页显示「录音卡」+ 录音卡状态胶囊（绿点心跳 + 电量）；进入子页变为「‹ Timeline」返回入口，顶栏吸顶。
- Timeline：按日分组倒序；卡片折叠两行（标题 / 时间·时长），点击展开摘要与说话人、再次点击收起；展开态「详情」按钮进详情页；卡片正文不导航。
- 总结：点击「总结」Tab 立即定位到「记录」并禁用其余 Tab（勾选场景只在记录内），时间轴进入勾选模式（全选今日 / 本周 / 本月）；底部操作栏两行——上行唯一计数「已选 N 项」、下行「取消 / 生成总结」。点击生成后立即切到总结页生成态：进度条 + 「已生成 X 秒 / 预计还需 Y 秒」 + 当前步骤（解析来源 → 提炼要点 → 整理结构，约 6 秒），期间可返回，完成后结果就地填充；时间轴 Action Card 同步显示进度，完成前锁定。
- 总结结果页：顶部为内容标题 + 统计行；标题下方为 Tab 结构——全部 / 概览 / 逻辑结构 / 信息点 / 行动项 / 来源记录（「全部」展示完整内容，不含 Markdown 原文）。信息点按内容结构化（标题 + 分析细节 + 溯源链接），点击展开/收起，溯源链接直达对应记录详情；「来源记录」Tab 列出全部被勾选的原始记录、可跳转；记录详情页有反向链接「已生成总结 N」列出引用该记录的全部总结，双向闭环。右上角为「导出」：完整文档 / Markdown / PDF / 图片 / Word，导出模拟调起系统级分享。
- 详情页：「对话详情 / 原始数据 / 被引用总结 N」平级 tab（被引用总结仅在 N>0 时显示，列出引用该记录的全部总结、可跳回结果页），说话人气泡排版；手机宽度下子页隐藏底栏，经顶栏返回（真机另支持边缘滑动返回）；顶栏面包屑在总结→详情链路上显示「‹ 总结」。
- 宽屏自适应：≥720px 切换「左列表 + 右详情」双栏，左栏 Timeline 常显（对照查看），无选中时右侧空态引导；顶栏与底栏高度固定（56px），中间撑满；宽屏下顶栏面包屑停用，嵌套查看时在面板内标题左侧显示「‹ 返回总结 / ‹ 返回记录」。
- 路由栈（历史扁平化）：总结 ↔ 来源记录互跳共用一个历史栈；跳向栈内已存在的页面时直接截断回该层（A→B→C→B 等价于 A→B），返回时弹栈至更外层，杜绝无限嵌套；回到根 Tab 即清空。窄屏保留顶栏面包屑（‹ 总结 / ‹ 记录 / ‹ Timeline），宽屏以面板内返回按钮代替。
- 录音卡状态页（胶囊弹层）：严格单行布局（标签左、值右对齐，超长省略）——录音状态、电量 + 预计可录制到几点（按耗电保守估算）、实时同步（蓝牙切片边录边传）+ 最近同步、Wi-Fi 配置状态、固件版本（仅待更新时显示「可更新 ›」入口，点击进蓝牙升级流程）；底部「重新配置 Wi-Fi / 同步上传」+ 关闭；转录相关配置在 Setting。
- Tab：全部 / 记录 / 总结。
- 界面按真实上线形态呈现，不出现「模拟 / 演示」标注（owner 指示）；原型边界声明保留在本文件与 AGENTS.md。

## 边界（重要）

纯本地原型：未接真实 BLE、ASR、声纹、LLM 或云端服务，数据全部为本地预置示例；说话人为推测归类示例，不断言真实身份。界面按真实上线形态呈现、不在页面内标注模拟字样（owner 指示，2026-11-07）。SDK 实际可支撑范围见 `docs/SDK-CAPABILITY.md`。
