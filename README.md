## 当前设计基线（2026-11-07 v3 打磨）

- 顶栏即导航：首页显示「录音卡」+ 录音卡状态胶囊（圆点：绿=正在录音 · 心跳、橙=已连接未录音、灰空心=未连接；电池图标仅连接后显示，按电量 <20% 红 / <40% 橙 / ≥40% 绿三色，不显示数字）；进入子页变为「‹ Timeline」返回入口，顶栏吸顶。
- Timeline：按日分组倒序（今天→昨天→更早）。每天分组内：日终产物（日报/总结/未归类图片）在顶部 → 普通记录按时间从晚到早 → 做梦卡（当天最早事件）在底部；卡片折叠两行（标题 / 时间·时长），点击展开摘要与说话人、再次点击收起；展开态「详情」按钮进详情页；卡片正文不导航。 记录标题右侧带相册缩略图：45px 正方形（与标题+时间同高），1 张单图、2~3 张层叠、超过 3 张第 4 层显示总数；标题/时间单行省略。
- 总结：点击「总结」Tab 立即定位到「记录」并禁用其余 Tab（勾选场景只在记录内），时间轴进入勾选模式（全选今日 / 本周 / 本月）；底部操作栏两行——上行唯一计数「已选 N 项」、下行「取消 / 生成总结」。点击生成后立即切到总结页生成态：进度条 + 「已生成 X 秒 / 预计还需 Y 秒」 + 当前步骤（解析来源 → 提炼要点 → 整理结构，约 6 秒），期间可返回，完成后结果就地填充；时间轴 Action Card 同步显示进度，完成前锁定。生成完成后总结卡放在它覆盖的最新一天分组顶部（普通记录上方）；总结没有详情页，点整张卡直接进结果页。
- 相册、总结配图、记忆图谱、睡前日记、梦境漫画与灵动岛 Agent（2026-11-10 ~ 2026-11-13）：记录标题右侧相册缩略图（45px 正方形、与标题+时间同高；1 张单图 / 2~3 张层叠 / >3 张第 4 层显示总数）。对话详情按照片时间把图片插进对话流，可标记「不属于本段」归入当天顶部「未归类图片」；点击「未归类图片」打开半屏分拣抽屉一键归位或忽略移除。总结结果页在概览、逻辑结构（核心实证微缩图 vs 辅助图标）、信息点、行动项（按需 `@说话人`/期限/原话定位/现场图芯片）与来源记录卡片中融入图片。端侧声纹聚类结合大模型上下文呼语（如点单喊称呼）推断说话人姓名，确认后持续沉淀人物资料，并在日间清洗与夜间做梦中整理进「事件（Event/Story）— 可升格为点的关系（Relation）— 实体/对象（人/物/私有概念）」三元记忆图谱。「睡前日记」（原日报升级）以有趣叙事记录今日所做与推理（支持点赞），每次提供 1~5 个待确认轻标注反哺次日做梦；「做梦完成」按需展示 4~6 格天马行空梦境漫画 + 每日总结，发现重复 2~3 次事项主动提醒并提炼为复用 Skill。录音卡物理按键支持单击打重点（Mark）、长按免掏手机唤起灵动岛语音提问并先后推送 A【立即回执】与 B【记忆结果】两条消息、双击预留；未在 App 落地的超前设计统一标 `TBC`。
- 总结结果页：顶部为内容标题 + 统计行；Tab 栏吸顶（滚动中持续可见，文字不换行、宽度不足横向滑动），栏右端常驻「目录」浮钮（点开跳转段落，非「全部」Tab 会先切回「全部」）；Tab 结构——全部 / 概览 / 逻辑结构 / 信息点 / 行动项 / 来源记录（「全部」展示完整内容，不含 Markdown 原文）。信息点按内容结构化（标题 + 分析细节 + 溯源链接）：「全部」默认收起、切到「信息点」默认全部展开；「来源记录」Tab 列出全部被勾选的原始记录、可跳转；记录详情页有反向链接「已生成总结 N」列出引用该记录的全部总结，双向闭环。页头右上「导出」：完整文档 / Markdown / PDF / 图片 / Word，导出模拟调起系统级分享。
- 详情页：「对话详情 / 原始数据 / 被引用总结 N」平级 tab（被引用总结仅在 N>0 时显示，列出引用该记录的全部总结、可跳回结果页），说话人气泡排版；手机宽度下子页隐藏底栏，经顶栏返回（真机另支持边缘滑动返回）；顶栏面包屑在总结→详情链路上显示「‹ 总结」。
- 宽屏自适应：≥720px 切换「左列表 + 右详情」双栏，左栏 Timeline 常显（对照查看），无选中时右侧空态引导；顶栏与底栏高度固定（56px），中间撑满；宽屏下顶栏面包屑停用，嵌套查看时在面板内标题左侧显示「‹ 返回总结 / ‹ 返回记录」。
- 路由栈（历史扁平化）：总结 ↔ 来源记录互跳共用一个历史栈；跳向栈内已存在的页面时直接截断回该层（A→B→C→B 等价于 A→B），返回时弹栈至更外层，杜绝无限嵌套；回到根 Tab 即清空。导航来源区分：左栏列表点击是根级新选择（栈重置，不产生返回按钮），面板内链接才压栈；返回文案由页面注册表派生。路由栈与已生成总结持久化在 sessionStorage（同标签页刷新不丢、关页自动清），启动时自动恢复。窄屏保留顶栏面包屑（‹ 总结 / ‹ 记录 / ‹ Timeline），宽屏以面板内返回按钮代替。
- 录音卡状态页（胶囊弹层）：严格单行布局（标签左、值右对齐，行高加高）——录音状态（红点「录音中」+ 实时跳动时钟 h:mm:ss，定宽等宽字体防抖动）、电量（电池图标 + 高/中/低三档，不显示百分比 + 可录至时点按耗电保守估算）、同步（自动同步为主：行文案「自动同步 · 相对时间」，刚刚 / 30 秒前 / N 分钟前阶梯；点击行 = 手动同步；不放旋转图标）、Wi-Fi（已配置 · N 个网络；点击进二级页：已保存网络置顶、默认前 3 个 +「查看更多已保存」展开，扫描范围外的保存网络置灰；分割线下为可用网络——已保存且在范围内点击直连，新网络输入并保存密码后连接；名称密码存 localStorage 模拟、硬件端只保留最后一次连接；仅显示 2.4GHz 网络）、固件（仅待更新时显示入口；两阶段更新：主控芯片 + Wi-Fi 芯片，版本对比在更新页呈现，更新中禁用返回、点空白处弹层不关闭并提示勿退出）。同步 / Wi-Fi / 固件三行行内可点（右侧 › 箭头），分别触发同步上传、Wi-Fi 设置页、固件更新；同步行状态机：› → 旋转 loading（正在同步…）→ 绿色对勾（同步成功 · 刚刚），成功后 10 秒冷却禁点；底部仅「关闭」；转录相关配置在 Setting。

- 连接与录音流程（2026-11-09）：默认未连接（胶囊灰点）；点开先「连接录音卡」并自动扫描，只列 DYJ 系列、按 RSSI 从强到弱排序。连接后默认未录音，录音状态行本身是开关，打开后红点 + 正计时。设备约 5 分钟一个切片，每片转写完成后作为「今天」第一条进入 Timeline；顶部「正在录音 · 未转录 / 正在同步」状态块表示当前尚未转录的部分（积压上限约 30 分钟），不可点、不参与总结勾选。停止录音自动同步，手动点同步行才算手动同步。
