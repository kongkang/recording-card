## 2. 免费版与四档会员结构（最终确认稿）

### 2.1 免费版（Free）
- **额度口径**：**每月 3,600 分钟（60 小时）灵活总池，不设单日上限**，每月 1 日 00:00 重置。日常每天开会 2~3 小时完全免费够用，靠良心建立口碑。
- **满额保护（硬原则）**：当月 3,600 分钟耗尽后，**绝不中断录音**——硬件或手机录下的新音频继续安全落盘本机队列，界面出现柔和提醒条，提示次月 1 日恢复免费转写或升级解锁。

### 2.2 本地音频转文本解锁版（Local Pro）
- **定位**：低门槛拉新 + 永久买断锁定未来桌面端 / 自配 API Key（BYOK）用户，边际云成本 ≈ **¥0**。
- **定价**：
  - 月付：**¥6 / 月**（海外 **$0.99**）——15% 苹果税后实收 **¥5.10**
  - 年付：**¥68 / 年**（海外 **$9.99**）——15% 苹果税后实收 **¥57.80**（折合 ¥4.82/月）
  - 永久买断：**¥198**（海外 **$29.99**）——15% 苹果税后实收 **¥168.30**
- **核心权益**：无限本地离线转写、声纹区分与跨对话命名、相册按时刻对齐、完整文档/Markdown/PDF/Word/图片多格式导出、自接入第三方大模型（BYOK）与未来桌面端本地推理（**买断页明确声明：不包含官方云端 AI 算力额度**）。

### 2.3 云端 AI 会员 · 基本够用版（Cloud Basic）
- **模型底座**：全流程采用国内高性价比模型 **`DeepSeek-V4.1-Flash`**（或同等性价比 Flash/开源模型）。
- **定价**：**¥28 / 月** · **¥268 / 年**（海外 **$3.99 / \$39.99**）
  - 15% 苹果税后实收：月付 **¥23.80** / 年均 **¥18.98**
- **内含权益**：**打包包含全部 Local Pro 权益** + 每月 **500 AI 积分**（对应约 **100 小时**云端滚动清洗分段 + **150 次** Flash 结构化总结与记忆问答 + 每日夜间睡眠鼾声趋势报告）。
- **成本与毛利（全按最严苛 DeepSeek V4.1 高峰无缓存价 ¥2/¥8 锚定）**：
  - 单个用户极端拉满 500 积分成本封顶 **≤ ¥22 / 月**；加权平均保守成本 **¥11 / 月**（含空闲半价与提示词缓存实际约 **¥7.5 / 月**）。
  - 保守毛利率 **54%**（ROI **2.2×**），真实运营毛利率 **68%**（ROI **3.2×**）。

### 2.4 云端 AI 会员 · 专业版（Cloud Pro）
- **模型底座**：**混合旗舰路由**——后台高频清洗/话题分段与睡眠常规汇总仍走 `DeepSeek-V4.1-Flash`（¥0.135/h），用户肉眼可见的**核心总结、睡前日记与复杂记忆推理调用海外旗舰 `Gemini 3.1 Pro`**（$2/$12 per 1M ≈ ¥14.4/¥86.4，含思考 Token）。
- **定价**：**¥88 / 月** · **¥848 / 年**（海外 **$12.99 / \$129.99**）
  - 15% 苹果税后实收：月付 **¥74.80** / 年均 **¥60.07**
- **内含权益**：**打包包含全部 Local Pro 权益** + **120 小时 Flash 云端清洗** + **每月 50 次 Gemini Pro 旗舰深度总结/睡前日记 + 50 次 Pro 记忆问答**；当 Pro 旗舰次数用尽后，**自动无缝切换至 DeepSeek Flash 续用**，绝不突然断档。
- **成本与毛利（高峰无缓存锚定）**：
  - 单人封顶算力成本锁死 **≤ ¥56 / 月**（绝不穿仓）；加权平均保守成本 **¥38 / 月**（实际约 **¥28 / 月**）。
  - 保守毛利率 **49%**（ROI **2.0×**），真实毛利率 **63%**（ROI **2.7×**）。

## 4. `1.1.0` 工程降本与合规硬约束

1. **防重复触发与清洗降本**：将 `RollingCleanSegmentService` 默认批周期从 15 分钟优化至 30 分钟（或仅对高信息密度段触发），严格写入幂等水位防止重复调用；全天汇总优先基于单场摘要二次 Reduce，可减少约 35%–45% 冗余 Token。
2. **夜间睡眠鼾声 / 呼吸节律分析**：音频特征（鼾声时段、响度峰值、≥10 秒呼吸静默事件 JSON）必须由**端侧本地提取**，云端模型仅做文本化健康趋势整理；所有文案禁用“医疗诊断 OSA”等表述，遵守 Apple 1.4.1 审核规范。
3. **iOS IAP 合规（3.1.1 / 3.1.2）**：App 内订阅与积分包全部走 StoreKit 2，不得弹窗引导至微信/支付宝购买数字会员；付费墙底部必须包含自动续费条款说明、「恢复购买」按钮以及隐私政策/使用条款入口。
