# 录音卡 · 隐私政策

- **生效日期**：2026-11-13
- **适用产品**：「录音卡」iOS / Android App（bundle id `com.reai.recordingcard`）及配套硬件录音卡
- **运营方**：ReAI（下称「我们」）
- **联系邮箱**：privacy@reai.chat

> 本文件是完整条款，也是 App 内「设置 → 关于录音卡 → 隐私政策」页面（`app/lib/core/config/privacy_text.dart`）的来源。
> 两处内容必须同步修改；发版时本文件的生效日期要同步到 App Store Connect / Play Console 的政策链接页面。

---

## 一、一页读懂

1. **录音只存本机**：从录音卡同步的音频与转写文本默认只保存在你的手机里，不上传。
2. **上传只在你主动操作时发生**：只有你点击「生成总结」并确认使用云端转写，对应片段才会离开手机。
3. **蓝牙只用来连设备**：扫描结果不用于定位、不做画像。
4. **Wi-Fi 只用来给录音卡配网**：网络名称与口令只存在本机与设备上。
5. **没有广告 SDK**：不收集广告标识、不跨 App 追踪、不出售个人信息。
6. **随时可删**：单条删除、全部清空、撤回云端授权、注销账号都在 App 内完成。

## 二、我们处理的信息

| 类别 | 具体内容 | 用途 | 存放位置 | 保留期 |
| --- | --- | --- | --- | --- |
| 录音数据 | 从录音卡同步的音频文件、时间戳、打点标记 | 回放、转写、生成总结 | 手机沙盒（App 私有目录） | 直到你删除或卸载 App |
| 转写与总结文本 | 录音卡侧转写文本、App 生成的总结文档 | 展示、检索、导出 | 手机沙盒 | 同上 |
| 设备信息 | 录音卡蓝牙名称、电量、固件版本、Wi-Fi 配置状态 | 连接设备、展示状态、固件更新判断 | 手机本地 | 同上 |
| 配网信息 | 你输入的 Wi-Fi 名称与口令 | 给录音卡配置网络 | 手机本地 + 录音卡（只保留最后一次） | 直到你修改或清除 |
| 账号信息（仅在登录时） | 账号标识、登录令牌（支持通过外脑账号及外脑授权页提供的 Apple / Google 登录获取） | 识别账户、同步授权状态 | 令牌存系统密钥库（iOS Keychain / Android Keystore）；App 不收集你的第三方平台密码 | 直到退出登录或注销 |
| 微信登录（仅在你选择时） | 点击「微信登录」后通过微信 OpenSDK 获取的一次性授权码 | 向我们的服务端换取本应用登录令牌（不读取你在微信的其他信息） | 一次性内存态上送服务端换票，不落本地明文 | 换取令牌后即时失效 |
| 崩溃诊断（仅本机） | 最近一条错误的摘要与调用栈 | 你反馈问题时定位原因 | 手机本地（`rc.lastCrash`） | 只保留最近一条，被你覆盖或清除 |

**我们不收集**：通讯录、短信、相册、位置、麦克风环境音、剪贴板内容、其他无关的已安装应用列表（仅在启用微信登录时检测本机是否安装微信客户端，不枚举其他应用）、广告标识（IDFA / OAID / IMEI / Android ID 广告用途）。

## 三、录音与转写数据的存放

- 音频、转写文本、总结文档统一存放在 App 私有沙盒目录，系统相册与「文件」App 默认不可见；只有你主动导出并选择保存位置时，文件才会写到沙盒之外。
- 卸载 App 会随沙盒一起删除上述数据。**请注意：卸载不可恢复，重要录音请先导出。**
- App 不需要麦克风权限：录音在硬件录音卡上完成，手机只做同步与展示。

## 四、权限用途说明

| 平台 | 权限 | 用途 | 拒绝后果 |
| --- | --- | --- | --- |
| iOS | 蓝牙（`NSBluetoothAlwaysUsageDescription`） | 连接录音卡、同步录音、读取电量与录音状态、下发录音/打点命令 | 无法连接设备，历史记录仍可查看 |
| iOS | 本地网络（`NSLocalNetworkUsageDescription` + Bonjour） | Wi-Fi 配网时发现设备、写入网络配置 | 无法完成配网（可用蓝牙同步不受影响） |
| Android | `BLUETOOTH_SCAN` / `BLUETOOTH_CONNECT`（Android 12+） | 同上，扫描与连接录音卡 | 无法扫描/连接设备 |
| Android | `BLUETOOTH` / `BLUETOOTH_ADMIN` / `ACCESS_FINE_LOCATION` / `ACCESS_COARSE_LOCATION`（仅 Android 11 及以下） | 老系统上 BLE 扫描的系统要求 | 同上 |
| Android | `NEARBY_WIFI_DEVICES`（Android 13+）、`ACCESS_WIFI_STATE` / `CHANGE_WIFI_STATE` | 列网络、写配置、确认联网 | 无法配网 |
| Android | `INTERNET` / `ACCESS_NETWORK_STATE` | 可选云端转写、版本检查、固件更新下载 | 云端功能不可用 |

蓝牙与 Wi-Fi 权限在 Android 上声明了 `neverForLocation`：我们不使用蓝牙/ Wi-Fi 扫描结果推断你的地理位置。

## 五、云端转写与总结（可选功能）

- **触发条件**：你在「设置」里开启「自动转录 / 云端总结」，或在详情页主动点击「生成总结」。关闭开关后，后续录音不再上传。
- **上传内容**：你选中的录音片段（音频）与相关文本（说话人标记、时间戳）。
- **接收方**：经我们自建模型网关（`block2-api.wainao.chat`）转发给第三方语音识别（ASR）与语言模型（LLM）服务商，仅用于生成转写与总结。
- **不做的事**：我们与服务商均不将你的内容用于模型训练、不用于广告投放、不与第三方做数据交换。
- **保留期**：服务端处理结果保留 **30 天**，用于失败重试与问题排查，到期自动删除。
- **删除途径**：App 内删除对应记录 → 服务端副本在收到请求后 **15 天内**清除；也可发邮件到 privacy@reai.chat 请求删除。
- **传输安全**：全程 HTTPS/TLS。

## 七、数据共享与跨境

- 除上文「云端转写」外，我们**不向任何第三方共享**你的录音与个人信息。
- 不使用、不出售、不出租个人信息做营销。
- 云端转写涉及的模型服务商可能位于境外；该功能默认关闭，只有你主动开启并确认才会触发。

---

## 八、数据安全

- 录音与转写文本存放在 App 私有沙盒，其他 App 无法读取。
- 登录令牌保存在系统密钥库（iOS Keychain / Android Keystore），不落明文文件。
- 网络请求强制 HTTPS；Android 端已禁用明文流量，release 构建开启代码与资源压缩（R8）。
- 崩溃信息只在本机保留最近一条，用户可见、可清除。

## 九、你的权利与行使方式

| 权利 | 操作路径 |
| --- | --- |
| 查看 / 导出 | 详情页「导出」（完整文档 / Markdown / PDF / 图片 / Word） |
| 删除单条记录 | 时间轴对应记录 → 删除 |
| 清空本机全部数据 | 「设置 → 数据管理 → 清空本机数据」 |

注销与删除是**不可恢复**操作，请先确认重要录音已导出。
