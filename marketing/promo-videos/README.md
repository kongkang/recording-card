## 产品真实性红线核验（100% 遵循 `AGENTS.md`）

1. **零 TBC 界面实拍**：全部 25 张高分屏 UI 资产均只读截取自 `prototype/current.html`（已隐藏顶栏开发切换胶囊与原型状态切换条），绝不把未上线的 `TBC` 特性（如梦境漫画、三元记忆图谱）包装为已上线功能。
2. **隐私与本地优先诚实表述**：不向用户堆砌底层模型技术名词，聚焦「极致压缩的轻量化本地模型、省电流畅体验、原始音频数据全程留在本机绝不外传」。
3. **说话人推测边界**：所有界面与配音均如实呈现「说话人 1 / 2（推测）」，不断言真实身份。
