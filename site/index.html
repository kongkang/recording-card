03 / HARDWARE & LIVE ACTIVITY

不掏手机就能用，断连了也不丢话。

物理按键直接触发记忆检索，硬件优先与零功耗待命机制兼顾续航与可靠性。

物理按键交互定义

无需解锁手机或打开 App，盲按录音卡物理按钮即可完成标记与提问。

单击 · MARK 无感打重点。时间戳随音频写入，模型在总结与睡前日记中优先聚焦此处并推测打点意图。
长按 · COMMAND 唤起手机顶部灵动岛收听语音提问；松手后先推送 A【立即回执】，查完再推 B【记忆结果】。
双击 · RESERVED 暂空预留，后续支持绑定自定义快捷指令或特定 Skill。

硬件优先与零功耗保底

蓝牙正常录音期间手机麦克风绝不并行采集，避免手机发热耗电；只有意外发生时才接力。

正常连接 隐藏「本机录音」入口，由硬件低功耗采集并驱动 iOS 灵动岛与锁屏实况卡片。
意外断连 蓝牙失联、硬件没电或 OTA 重启时，手机本机录音立即自动启动接力，实况卡片无缝切换。
重连退回 硬件恢复连接后自动停掉手机麦克风，退回零功耗待命状态；手动停录则解除待命。
04 / ARCHITECTURE

对隐私和数据边界保持克制与诚实。

我们不在产品里包装黑魔法，每一条设计红线都在代码与文档中公开可查。

ON-DEVICE FIRST

音频默认不出本机

切片、VAD 检测、SenseVoice 语音转写与 CAM++ 声纹 embedding 提取均在手机本地执行；云端仅接收用于润色与总结的文本。

NO HALLUCINATED IDENTITY

说话人只做推测，不断言

未经过你手动确认的说话人永远展示「说话人 1 / 2（推测）」，低置信度片段如实显示「未区分」，保留原始映射可随时纠偏。

RAW DATA PRESERVED

清洗内容优先，原始记录永不销毁

对话详情与总结默认展示润色后的整洁文本，但原始转写与原始音频切片以低权重完整保留，随时可播放核对或删除。

OPEN SOURCE · AGPL-3.0

Rust BLE 桥接与全栈透明

App 基于 Flutter 构建，通过 Rust C-ABI 桥接 reai-card-sdk 直连真实硬件；OAuth2 PKCE 鉴权与自托管模型网关均可审计。
